# Pin It Down

変化していく意思決定を、保守される開発文書と安全なローカルGitチェックポイントへ落とし込みます。

Pin It Downは、Markdown形式の仕様書、技術設計書、実装計画書を作成・整合・レビュー・更新する、明示起動専用のCodexスキルです。粗いアイデアから必要な判断だけを質問して文書化することも、会話ですでに決まった内容を永続的なプロジェクト文書へ反映することもできます。

## 主な機能

- 依頼に必要な開発文書だけを作成します。
- 確定した要件、リポジトリの根拠、提案、未解決事項を区別します。
- 既存文書の無関係な内容を維持し、範囲を限定した差分で更新します。
- 文書への導線を将来のCodex作業に残す必要がある場合、プロジェクト直下の`AGENTS.md`または`AGENTS.override.md`を簡潔に保ちます。
- 実プロジェクトではローカルGitを整備し、文書作成の検証後にタスク範囲を限定したチェックポイントコミットを作成します。
- 矛盾、欠落、古くなった判断を、ファイルを変更せずに確認するレビューにも対応します。

## モード

| モード | 適した状況 |
| --- | --- |
| Discovery | 粗いアイデアから、結果を左右する判断をCodexと詰めたいとき。 |
| Capture | 重要な判断が現在の会話ですでに決まっているとき。 |
| Sync | 後から決まった内容を既存文書へ小さな差分で反映するとき。 |
| Review | ファイルを変更せず、監査や改善案だけが必要なとき。 |

## 管理するファイル

既存のプロジェクト文書規約があればそれを優先します。規約がなければ、次のパスを使用します。

```text
docs/SPEC.md
docs/DESIGN.md
docs/PLAN.md
```

実プロジェクトの文書書き込みでは、プロジェクト直下で有効な`AGENTS.md`または`AGENTS.override.md`の作成・最小更新、ローカルGitの初期化、プロジェクトの根拠に基づく`.gitignore`の補完、ローカルチェックポイントコミットも行う場合があります。Reviewモードと、セッションフォルダを代替出力先として使用する場合は、これらの連携を行いません。

## インストール

Codexに次のように依頼します。

```text
$skill-installerを使って https://github.com/LowestEffort/pin-it-down/tree/main/skills/pin-it-down をインストールしてください。
```

または、`skills/pin-it-down`を`$CODEX_HOME/skills/pin-it-down`（通常は`~/.codex/skills/pin-it-down`）へコピーします。インストール後は、新しいCodexタスクを開始するとスキルが認識されます。

## 使用例

このスキルは明示的に呼び出してください。通常の計画、実装、デバッグ、ブレインストーミングでは自動起動しません。

```text
$pin-it-down この粗いプロダクト案から仕様書・設計書・計画書を作れるところまで一緒に詰めてください。

$pin-it-down この会話で決まった内容をプロジェクト文書にまとめてください。

$pin-it-down 既存文書へ今決めた内容を同期してください。

$pin-it-down プロジェクト文書の矛盾と欠落をレビューしてください。ファイルは変更しないでください。
```

生成文書の言語は、依頼で使用された言語と、既存プロジェクト文書の言語・用語規約に従います。

## 安全上の境界

- 明示的に呼び出された場合のみ起動します。
- レビュー依頼は読み取り専用・提案のみです。
- アプリケーションコード、テスト、依存関係、フック、無関係な設定は変更しません。
- 依頼範囲外のユーザー作成文書とプロジェクト指示を維持します。
- `CODEX_HOME`または`~/.codex`配下のグローバルCodex指示は変更しません。
- Gitのステージ対象をタスク所有の明示的なファイルに限定し、コミット前に内容を検査します。
- Git履歴の書き換え、ユーザー情報やremoteの設定、pushは行いません。
- GitHub、課題管理サービス、その他の外部サービスへ公開しません。

## 謝辞

対話を通じて考えを詰める発想は、Matt Pocock氏の[`grill-me`](https://github.com/mattpocock/skills/tree/main/skills/productivity/grill-me)および[`grill-with-docs`](https://github.com/mattpocock/skills/tree/main/skills/engineering/grill-with-docs)から着想を得ています。Pin It Downは独立した実装であり、これらのスキルに依存せず、同梱もしていません。
